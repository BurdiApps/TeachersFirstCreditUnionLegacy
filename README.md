# Teachers First Credit Union

I created this fictional credit union website as a way to learn about legacy .NET systems. It uses ASP.NET Web Forms and .NET Framework, technologies that are different from the newer tools I’m learning about today. Building and exploring the project helps me understand how older applications are organized and how they continue to work.

I’m especially interested in learning about these systems because many organizations in Bakersfield still depend on technology that has been in place for years. I want to understand how developers maintain and improve those systems while keeping them reliable. This project is for practice only: the credit union, accounts, rates, and member information are fictional, and it does not handle real money.
